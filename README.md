# Url shortener service

Cервис по сокращению ссылок пользователей, который сохраняет длинную исходную ссылку и возвращает короткий хэш-код. При получении хэша от клиента проверяет его наличие в кэше/базе данных и перенаправляет клиента по сохраненной оригинальной ссылке в случае ее обнаружения. Сервис также может использоваться для предоставления временного/платного доступа сбора аналитики и т.д.
